# Vibe Diary

A quiet, local-first daily atmosphere & mood journal designed for GitHub Pages.

## Features

- **7 Atmospheric Vibes**: Capture the mood of each day (*Golden Hour*, *Rainy Calm*, *Crisp Focus*, *Soft & Tender*, *Slow Drift*, *Sunlit Spark*, *Late Stillness*) with an analog atmosphere color strip.
- **Sensory Anchors**: Record optional soundtrack, place, and compressed photo moments alongside your reflections.
- **Local-First & Private**: Entries live in your browser's `localStorage` with automatic draft saving — no accounts, no backend, no tracking.
- **Bilingual (`EN` / `中文`) & Dual Themes**: Instant English / Chinese switching and warm *Daylight Paper* / *Evening Ink* themes.
- **Data Portability**: Export/import full JSON backups or download your journal as a formatted Markdown file.

## Local Development

No build step required — open `index.html` directly or serve with any static server:

```bash
python3 -m http.server 8000
```
